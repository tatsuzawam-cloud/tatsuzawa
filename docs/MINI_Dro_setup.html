MINI_Dro 設定手順書

UGREEN NAS（DXP4800 Plus）を「自分専用のDropbox」にする ／ 対象：NAS・iPhone・iPad・Windows PC ／ 家の外からも使う
作成日：2026年9月29日

0. 結論と全体像

NASに「MINI_Dro」フォルダを作り、UGREENのアプリで全機器からつなぎます。Dropboxの契約は不要です。外出先からは「UGREENlink」という公式のリモート接続を使います。ルーターの設定は不要です。

機器使うもの動き方目安時間
NASUGOS Pro（ブラウザで操作）MINI_Droの保管場所。すべての元データがここに入る15分
iPhone / iPadアプリ「UGREEN NAS」アプリからMINI_Droを開く・保存する（家の中でも外でも）各5分
Windows PC
（後日でOK）		UGREEN NAS デスクトップアプリの「Sync & Backup」PCのフォルダとNASが自動で同じ中身になる（Dropboxと同じ）10分
iPhone・iPadの動き方について：iOSの仕組み上、裏側での常時フォルダ同期はできません。ファイルは「アプリで開いて使う」形です（DropboxのiOSアプリもほぼ同じ動き方です）。PCのように、何もしなくても中身がそろう動きはWindows・Macだけです。

準備するもの

  • NASの管理者アカウント（ユーザー名とパスワード）
  • メールアドレス（UGREENアカウント作成に使います。例：tatsuzawa.m@gmail.com）
  • iPhone・iPadがNASと同じ自宅のWi-Fiにつながっていること（初回の設定時）

※画面のメニュー名は、UGOS Proやアプリの版によって少し違うことがあります。見つからない場合は、近い名前のメニューを探してください。

1. NASの設定（パソコンまたはiPadのブラウザで）

1-1. UGOS Proにログインし、最新版に更新する

  1. ブラウザで find.ugnas.com を開き、NASを探してログインします（NASのIPアドレスが分かれば、それを直接入力してもOKです）。
  2. コントロールパネル → システム更新（または「更新と復元」）を開き、更新があれば実行します。
    理由：古い版だと、リモート接続や同期のメニューが出ないことがあります。

1-2. 共有フォルダ「MINI_Dro」を作る

  1. ファイルアプリを開き、左側の 共有フォルダ 横の ＋（または「共有フォルダを作成」）を押します。
  2. 名前に MINI_Dro と入力します（大文字・小文字もこのとおりに）。
  3. 保存先のストレージ（ボリューム1など）を選びます。
  4. ごみ箱は「有効」のままにします（新しい共有フォルダでは初期設定で有効です）。
  5. 権限：ご自身のアカウントを「読み取り／書き込み」にします。他の人には付けません。
  6. 保存します。
おすすめ：スナップショットも有効にする
ストレージ または スナップショット のメニューで、MINI_Droに「1日1回・30日分保存」のスナップショットを設定します。
理由：同期では「削除」も全機器に広がります。間違えて消したり、ウイルスでファイルを壊されたりしても、前の日の状態に戻せます。

1-3. 家の外から使えるようにする（UGREENlink）

  1. コントロールパネル → デバイス接続 → リモートアクセス を開きます。
  2. UGREENlink をオンにします。
  3. 画面の案内に従い、UGREENアカウントを作成（すでにあればログイン）して、NASと結び付けます。
  4. UGREENlink ID を決めて入力し、適用 を押します。
    　例：tz-mini-7k3q（会社名だけのIDは推測されやすいため避けます）
  5. 表示された UGREENlink ID と Webアクセス用のリンク を控えます。→ 最終ページの記入欄へ。

1-4. 安全対策（外から使うので必須）

  • パスワード：管理者アカウントは12文字以上の、他で使っていないものにします。
  • 2段階認証：右上の自分のアカウント（個人設定）→ セキュリティで、2段階認証をオンにします。スマホの認証アプリで確認コードを受け取る方式です。
  • 「admin」という名前のアカウントを使っている場合は、別名の管理者を作り、adminは無効にするのが理想です。

2. iPhone・iPadの設定（どちらも同じ手順）

2-1. アプリを入れてログインする

  1. App Storeで 「UGREEN NAS」（開発元：UGREEN）をインストールします。iOS 15以上が必要です。
  2. 自宅のWi-Fiでアプリを開くと、NASが自動で見つかります。選んで、NASのユーザー名とパスワードでログインします。
  3. 家の外でつなぐ場合は、ログイン画面で UGREENlink ID（1-3で決めたもの）を入力します。一度ログインすれば、その後はアプリが自宅と外出先を自動で切り替えます。

2-2. MINI_Droをすぐ開けるようにする

  1. アプリ下の ファイル → MINI_Dro を開きます。
  2. 右上のメニュー（…）から お気に入り（またはピン留め）に入れておきます。

2-3. 使い方

したいこと操作
ファイルを入れるMINI_Dro内で ＋ →「ファイル」または「写真」を選ぶ
メール添付をしまう添付を長押し → 共有 → 「UGREEN NAS」→ MINI_Droを選ぶ
ファイルを見るタップで開く（PDF・写真・動画・Office文書はアプリ内で表示）
他のアプリで編集ファイルの …→「別のアプリで開く」。編集後は保存し直してアップロードします

おまけ：家の中では「ファイル」アプリからも使えます（iPhone・iPadに最初から入っているアプリ）
「ファイル」アプリ → 右上の … → サーバへ接続 → smb://NASのIPアドレス（例：smb://192.168.1.20）→ NASのユーザー名とパスワード → MINI_Dro。
Word・Excel・PDFを直接開いて上書き保存できます。家のWi-Fiの中だけで使える方法です。外出先ではUGREEN NASアプリを使います。
NASのIPアドレスは、UGOS Proの コントロールパネル → ネットワーク で確認できます。

3. Windows PCの設定（後日でOK）

この設定で、PCの「MINI_Dro」フォルダとNASの中身が自動でそろいます。Dropboxと同じ使い心地です。

  1. UGREENのダウンロードページ（ugreen.com → アプリダウンロード）から、UGREEN NAS デスクトップアプリ（Windows版）を入れます。
  2. アプリを開き、NASにログインします（家の外にあるPCなら、UGREENlink IDでログイン）。
  3. PC側に空のフォルダを作ります：C:\Users\（ご自身のユーザー名）\MINI_Dro
  4. アプリで Sync & Backup → 左メニュー 同期（Sync） → 追加 → このコンピューターを同期 → 次へ。
  5. パソコン側のパス：手順3のフォルダ ／ NAS側のパス：/MINI_Dro
  6. 同期の方向は 双方向 を選びます。
  7. 重複したときの扱い（競合ルール）は、「両方残す」（名前を変えて両方保存）を選びます。上書き系は選びません。
  8. 完了を押すと、最初の同期が始まります。
  9. 設定で 「Windows起動時に自動起動」をオンにします。
    理由：アプリが動いていない間は同期されません。
最初の同期の前に：PC側・NAS側の両方にファイルがあると、重複や思わぬ上書きが起きやすくなります。PC側は空のフォルダから始めてください。PCにある既存のファイルは、同期が終わってから移します。

4. 必ず知っておいてほしい注意点

  1. 削除も同期されます。どの機器で消しても、NASからも消えます。→ 1-2の ごみ箱 と スナップショット で戻せるようにしておきます。
  2. NASだけではバックアップになりません。RAIDは「ディスク1台の故障」への備えで、火事・盗難・誤削除・ウイルスには効きません。
    → 大事なものは、外付けHDDへの自動バックアップ（1〜2万円程度）か、クラウドへのバックアップ（UGOS Proの「Cloud Drives」機能で、Dropbox・Google Driveなどへ定期コピー）を、もう1か所に用意します。
  3. 外出先での速さは、自宅回線の「上り」速度で決まります。大きな動画などは時間がかかることがあります。
  4. 会社の書類を入れる場合：個人情報・取引先の機密は、共有リンクを出さない運用にします。社員に使わせる場合は、一人ずつアカウントを作り、フォルダごとに権限を分けます。
  5. NASの電源は常に入れておきます。停電対策として、小型UPS（無停電電源装置、1〜2万円程度）があると安心です。
